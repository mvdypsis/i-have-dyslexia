# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be kind. Assume good intent.
- Never mock spelling, grammar or how someone writes. Here, that matters most.
- Respect that dyslexia is different for everyone.
- No harassment of any kind.

## Reporting

To report a problem, open a private
[security advisory](https://github.com/mvdypsis/i-have-dyslexia/security/advisories/new)
or contact the maintainer through their GitHub profile.
Reports are kept private.
