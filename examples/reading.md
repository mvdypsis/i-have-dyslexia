# Reading examples

## 1. Explaining a concept

The person asks: **"what is an API"**

Without the skill:

> An API, or Application Programming Interface, is a set of defined rules and protocols that allows different software applications to communicate with each other, specifying the kinds of requests that can be made, how to make them, the data formats that should be used, and the conventions to follow.

With the skill:

> **An API is how two programs talk to each other.**
>
> Think of a waiter in a restaurant.
> You (one program) give your order to the waiter (the API).
> The waiter takes it to the kitchen (the other program) and brings back your food (the data).
>
> In short: an API carries requests and answers between programs.

## 2. Summarising a long email

The person pastes a long email and asks: **"what does this want from me"**

With the skill:

> **They need your signature on the contract by Thursday 9 October.**
>
> - The price went up by **5%** because of shipping.
> - Delivery moved to **November**.
> - Legal already approved the new terms.
>
> To do: sign and send it back by Thursday.
