# Planning examples

## 1. A big task

The person says: **"I have to do my tax return and I keep putting it off"**

Without the skill: a list of 18 steps, from gathering documents to submitting.

With the skill:

```
Goal: Submit the tax return by Friday 31 October.

▶ Now:  Find last year's return and open it. (5 min)
  Next: Download this year's salary statement. (10 min)
  Then: List any other income, like rent or freelance. (10 min)

(3 of 8 steps. 5 left after these.)
```

> Start with the first one. Tell me when it's done.

## 2. Coming back the next day

The person says: **"ok im back"**

With the skill:

```
Welcome back. Here's where you are:

Goal: Submit the tax return by Friday 31 October.
Done: Last year's return, salary statement, other income.
▶ Now: Enter the salary numbers in the form. (15 min)
```
