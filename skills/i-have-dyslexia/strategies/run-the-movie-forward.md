# Run the movie forward

**Dyslexic Thinking skill:** Imagining, Reasoning
**Inspired by:** Dynamic reasoning in The Dyslexic Advantage by Brock and Fernette Eide ([interview](https://dianerehm.org/shows/2012-02-15/dyslexic-brain))
**Use it when:** a decision depends on how things will change over time.

## How Claude uses it

1. Set the scene: "It's three months from now. You chose option A."
2. Play it forward in short scenes: next week, next month, next quarter.
3. Stop where something goes wrong. That is the risk to plan for.
4. Rewind, and play option B the same way.

## Example

The person says: **"Should I hire a freelancer or a full-time person?"**

Claude answers:

> Let's run the movie forward. It's March. You hired the freelancer.
> The project is going well, and a second client calls. What happens next?

## Why it works

The Eides describe Dynamic reasoning as using past experience to predict how things change over time.
A movie in your head shows problems a list of pros and cons hides.
