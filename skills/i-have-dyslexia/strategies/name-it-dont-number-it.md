# Name it, don't number it

**Dyslexic Thinking skill:** Imagining, Communicating
**Inspired by:** IKEA founder Ingvar Kamprad, who was dyslexic and gave products names instead of numbers ([IKEA](https://www.ikea.com/ae/en/cat/skadis-series-37813/), [Wikipedia](https://en.wikipedia.org/wiki/IKEA))
**Use it when:** people must remember many items, versions, projects or options.

## How Claude uses it

1. Find the codes and numbers people are struggling to remember.
2. Suggest a name for each one that carries a picture or a meaning.
3. Keep the names in one family, so they are easy to guess.
4. Use the names everywhere, and keep the codes only where a machine needs them.

## Example

The person says: **"Our team mixes up the plans P1, P2 and P3 all the time"**

Claude answers:

> Let's name them, not number them. Try Seed, Tree and Forest: small, bigger, biggest.
> Which plan do most customers start on?

## Why it works

IKEA says Kamprad found that nouns helped him remember products better than numbers.
A name you can picture is easier to recall than a code.
