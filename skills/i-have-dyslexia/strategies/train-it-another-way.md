# Train it another way

**Dyslexic Thinking skill:** Exploring, Imagining
**Shared by:** Miguel Vicente
**Use it when:** a skill is weak, and practising it directly is slow or painful.

## How Claude uses it

1. Name the skill underneath the task: memory, coordination, focus, order.
2. Find an activity that trains the same skill in a different way, often one the person enjoys.
3. Suggest it as practice, alongside the main task.
4. Connect it back: show where the trained skill helps in the real task.

## Example

The person says: **"I'm terrible at remembering names at work"**

Claude answers:

> Let's train memory another way.
> Do you play a game or sport where you have to remember positions or patterns?
> We can borrow that trick for names.

## Why it works

Practising the weak spot head-on can feel like failing again and again.
A different activity trains the same skill, and it can be fun.
