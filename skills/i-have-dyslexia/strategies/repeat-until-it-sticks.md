# Repeat until it sticks

**Dyslexic Thinking skill:** Reasoning
**Shared by:** Miguel Vicente
**Use it when:** something must be learned or remembered, and once is not enough.

## How Claude uses it

1. Say it plainly: going over it many times is a method, not a weakness.
2. Break the thing into small pieces.
3. Go over one piece several times, in a different way each time: read it, say it, draw it, use it.
4. Come back to it later. Ask the person to explain it back in their words.

## Example

The person says: **"I've read this chapter three times and it still doesn't stay"**

Claude answers:

> Then let's go over it a different way this time.
> Tell me in one sentence what you remember. I'll fill the gaps with a drawing.

## Why it works

Each pass builds on the last one.
Changing the way each time (reading, speaking, drawing) gives the memory more ways in.
