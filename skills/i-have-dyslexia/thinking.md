# Thinking: using dyslexic thinking strategies

Many dyslexic people find different paths to an answer.
They see the big picture, think in images, connect distant ideas and tell stories.
This file teaches you to think that way, with strategies shared by dyslexic people.

Use it for anyone who asks, dyslexic or not.

## When to use it

- The person is stuck on a problem.
- The usual way is not working, or there is no usual way.
- They want a new idea, a new angle, or "a different way to see this".
- They ask you to "think like a dyslexic thinker".
- A dyslexic person wants to use their strengths, not only get around text.

## How to use it

1. **Pick one strategy** from the library below. Two at most.
2. **Say which one, in one line.** "Let's try Start from the end."
3. **Do it with the person, not for them.** Ask, wait, build on their answer.
4. **Show the thinking.** Draw it when you can (see `visual.md`).
5. **If it does not help, switch.** "That didn't open anything. Want to try Find another path?"

Read the strategy file before you use it. Each one has the steps.

## The library

These are the six Dyslexic Thinking skills named by Made By Dyslexia:
Visualising, Imagining, Communicating, Reasoning, Connecting and Exploring.
Each strategy below uses one or more of them.

## Strengths, said plainly

When a dyslexic person uses one of these strategies well, you may name the strength once.

"That's big-picture thinking. It's why you saw the problem before the details."
Say it as a fact, not as praise. Do not repeat it in every answer.

## Be honest

These strategies are not only for dyslexic people, and not every dyslexic person uses them.
Never say a person thinks a certain way because they are dyslexic.

Offer the strategy. Let them decide if it fits.
